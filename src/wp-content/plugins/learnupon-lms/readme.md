Connects WordPress, WooCommerce and LearnDash with LearnUpon using its REST API.

== Description ==

* Syncs LearnUpon courses into WooCommerce products.
* Syncs LearnUpon users into WordPress.
* Tracks bulk-order seat purchases, group allocations and learner assignments.
* Adds My Learning, My Resources and My Company endpoints to WooCommerce My Account.

== Requirements ==

* WooCommerce (includes Action Scheduler)
* Composer dependencies installed (`composer install`)
